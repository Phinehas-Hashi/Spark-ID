# Spark ID

**One identity. Every opportunity.**

Spark Stack International's Android identity app. This first milestone is a Jetpack Compose **UI preview**, not an authentication service.

## Current screens
- Welcome
- Login and registration (disabled until backend configuration)
- Dashboard preview
- Digital identity card preview

## Run
Open the repository in Android Studio, let Gradle sync, and run the `app` configuration. Windows CLI: `.\\gradlew.bat assembleDebug`.

## Security status
No real accounts, identity verification, issued credentials, wallet balances, OAuth provider, or backend calls exist in v0.1. Never enter real credentials for testing. Appwrite authentication and protected data access are future milestones.
